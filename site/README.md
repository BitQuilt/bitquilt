# bitquilt.com

One static page, no build step and no framework: `index.html` with its styles and its script inside, and fonts from Google Fonts. Serve the folder as it is; GitHub Pages, Vercel or any file server will do.

The quilt on the page plays back a fixed sequence of events so it looks the same each time; in Quilt the events arrive from strangers. The colours of the squares mean what they mean in the app.
